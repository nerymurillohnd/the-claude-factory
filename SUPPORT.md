## 🗂️ Open an issue

| I want to… | Use |
| :-- | :-- |
| Report a bug | [🐞 Bug report](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=bug_report.yml) |
| Suggest an improvement | [✨ Feature request](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=feature_request.yml) |
| Propose a new plugin | [💡 Plugin idea](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=plugin_idea.yml) |
| Fix the docs | [📝 Documentation issue](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=docs_issue.yml) |
| Ask something | [❔ Question](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=question.yml) |

We read every issue. Clear reproduction steps and versions (`claude --version`, `claude plugin list`) get the fastest answers.

## 🔐 Security

Never report vulnerabilities in public issues — follow the [Security policy](./SECURITY.md).

## 🧰 Not a plugin problem?

Issues with Claude Code itself, `/plugin`, or the Claude apps belong to [anthropics/claude-code](https://github.com/anthropics/claude-code/issues).
