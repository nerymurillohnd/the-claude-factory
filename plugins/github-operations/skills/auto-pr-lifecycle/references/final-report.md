# Final report

Close every run, whatever its outcome, with:

- Repository and PR URL.
- Final lifecycle outcome (one from `SKILL.md`).
- Final observed head SHA.
- Approved head SHA and resulting landing commit, if merged.
- Every commit created and pushed during the run.
- Final checks and workflow status.
- Failed jobs encountered, their locations, causes and fixes.
- Review totals, distinct findings and their dispositions.
- Remaining warnings, deprecations or dependency concerns.
- Dependabot findings and alert-coverage limitations.
- Optimization recommendations, marked non-blocking.
- Conflicts or base updates handled.
- Merge method, queue state and source of the landing confirmation.
- Post-merge workflow or deployment state, if observed.
- Cleanup and synchronization results.
- Remaining blockers or user actions.
- For each action, whether the MCP tools or the `gh` fallback completed it.

Do not repeat the whole monitoring history. Summarize the evidence, changes, final state and outstanding work.
