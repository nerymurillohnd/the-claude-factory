# Phase 4: Build

How to scaffold the skill and write the files the approved plan lists, checking each as it lands.

Create the skill's folder and the subfolders the plan lists, then write each file the plan lists. As each lands, check that its links resolve and that it reaches nothing outside its folder except through a path variable written in `SKILL.md`. Record each deviation from the plan and its reason.

Write each file as Phase 2 taught: reread the Phase 2 file that governs a part, such as the writing style for text or the scripts file for a script, when you reach it. If you can't write files, give each file's path and content in your reply.

Exit: every planned file exists and passes the link and folder checks above.
