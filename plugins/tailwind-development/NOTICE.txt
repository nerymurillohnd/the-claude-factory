This plugin routes Claude to third-party sources and records where they are.
It reproduces no documentation pages, code examples or figures from them.
The sources it quotes are listed below with what is quoted.

1. Tailwind CSS documentation (tailwindcss.com)

  Site:        https://tailwindcss.com/docs
  Source:      https://github.com/tailwindlabs/tailwindcss.com
  License:     none. The repository states that the project is not
               licensed under an open-source license and is the
               intellectual property of Tailwind Labs Inc.
  Checked:     2026-10-27, Tailwind CSS v4.3.3

  Files that list navigation data taken from the site (page URLs, page
  slugs, section heading ids and labels, and each page's one-line meta
  description; no page content):

  skills/tailwind-official-docs/SKILL.md
      the topic index of page slugs and the framework-guide slugs.
  skills/tailwind-official-docs/references/core-concepts/*.md,
  base-styles.md, layout.md, flexbox-and-grid.md, spacing.md, sizing.md
      each page's URL, meta description and h2 and h3 headings.

  Everything these files say about how to use the pages is original.

2. Tailwind CSS (tailwindlabs/tailwindcss)

  Repository:  https://github.com/tailwindlabs/tailwindcss
  Commit:      8cc0551b1217d36dc565840b90920964d37cb46c
  License:     MIT, Copyright (c) Tailwind Labs, Inc.

  Read as reference, with no material copied into this plugin: the
  CHANGELOG and GitHub releases (version questions, the 4.2 changes), the
  package READMEs, and the CLI's own behaviour (measured with
  @tailwindcss/cli 4.3.3). If later versions of this plugin copy files from
  this repository, they are listed here with their changes, and the MIT
  license text is included below, as its terms require.

  Claude Code downloads these from the npm registry into the plugin's own

  package-lock.json pins. They are not part of this repository. Each package
  carries its own license file.

      MIT, Copyright (c) Tailwind Labs, Inc.

      https://github.com/modelcontextprotocol/typescript-sdk
  vscode-jsonrpc 9.0.3

      https://github.com/microsoft/vscode-languageserver-node
