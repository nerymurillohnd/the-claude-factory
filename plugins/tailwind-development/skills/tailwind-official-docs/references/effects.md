## [box-shadow](https://tailwindcss.com/docs/box-shadow)

Utilities for controlling the box shadow of an element.

- [Examples](https://tailwindcss.com/docs/box-shadow#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/box-shadow#basic-example): `shadow-sm`, `shadow-lg`
  - [Changing the opacity](https://tailwindcss.com/docs/box-shadow#changing-the-opacity): Opacity modifier, such as `/75`
  - [Setting the shadow color](https://tailwindcss.com/docs/box-shadow#setting-the-shadow-color): `shadow-indigo-500`, `shadow-cyan-500/50`
  - [Adding an inset shadow](https://tailwindcss.com/docs/box-shadow#adding-an-inset-shadow): `inset-shadow-xs`, `inset-shadow-sm`
  - [Setting the inset shadow color](https://tailwindcss.com/docs/box-shadow#setting-the-inset-shadow-color): `inset-shadow-indigo-500`, `inset-shadow-cyan-500/50`
  - [Adding a ring](https://tailwindcss.com/docs/box-shadow#adding-a-ring): `ring-<number>`
  - [Setting the ring color](https://tailwindcss.com/docs/box-shadow#setting-the-ring-color): `ring-indigo-500`, `ring-cyan-500/50`
  - [Adding an inset ring](https://tailwindcss.com/docs/box-shadow#adding-an-inset-ring): `inset-ring-<number>`
  - [Setting the inset ring color](https://tailwindcss.com/docs/box-shadow#setting-the-inset-ring-color): `inset-ring-indigo-500`, `inset-ring-cyan-500/50`
  - [Removing a box shadow](https://tailwindcss.com/docs/box-shadow#removing-a-box-shadow): `shadow-none`, `inset-shadow-none`, `ring-0`, `inset-ring-0`
  - [Using a custom value](https://tailwindcss.com/docs/box-shadow#using-a-custom-value): Arbitrary values: `shadow-[<value>]`, `inset-shadow-[<value>]`, `ring-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/box-shadow#responsive-design): Breakpoint variants, such as `md:`
- [Customizing your theme](https://tailwindcss.com/docs/box-shadow#customizing-your-theme): Theme variables for these utilities
  - [Customizing shadows](https://tailwindcss.com/docs/box-shadow#customizing-shadows): `--shadow-*`
  - [Customizing inset shadows](https://tailwindcss.com/docs/box-shadow#customizing-inset-shadows): `--inset-shadow-*`
  - [Customizing shadow colors](https://tailwindcss.com/docs/box-shadow#customizing-shadow-colors): `--color-*`
