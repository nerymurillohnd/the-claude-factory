# Transitions & Animation

## [transition-property](https://tailwindcss.com/docs/transition-property)

Utilities for controlling which CSS properties transition.

- [Examples](https://tailwindcss.com/docs/transition-property#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/transition-property#basic-example): `transition`, `transition-colors`
  - [Supporting reduced motion](https://tailwindcss.com/docs/transition-property#supporting-reduced-motion): `motion-safe`, `motion-reduce`
  - [Using a custom value](https://tailwindcss.com/docs/transition-property#using-a-custom-value): Arbitrary values: `transition-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/transition-property#responsive-design): Breakpoint variants, such as `md:`
