# Backgrounds

## [background-attachment](https://tailwindcss.com/docs/background-attachment)

Utilities for controlling how a background image behaves when scrolling.

- [Examples](https://tailwindcss.com/docs/background-attachment#examples): Examples of each utility
  - [Fixing the background image](https://tailwindcss.com/docs/background-attachment#fixing-the-background-image): `bg-fixed`
  - [Scrolling with the container](https://tailwindcss.com/docs/background-attachment#scrolling-with-the-container): `bg-local`
  - [Scrolling with the viewport](https://tailwindcss.com/docs/background-attachment#scrolling-with-the-viewport): `bg-scroll`
  - [Responsive design](https://tailwindcss.com/docs/background-attachment#responsive-design): Breakpoint variants, such as `md:`

## [background-color](https://tailwindcss.com/docs/background-color)

  - [Basic example](https://tailwindcss.com/docs/background-color#basic-example): `bg-white`, `bg-indigo-500`, `bg-transparent`

## [background-image](https://tailwindcss.com/docs/background-image)

Utilities for controlling an element's background image.

- [Examples](https://tailwindcss.com/docs/background-image#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/background-image#basic-example): `bg-[<value>]`
  - [Adding a linear gradient](https://tailwindcss.com/docs/background-image#adding-a-linear-gradient): `bg-linear-<angle>`
  - [Adding a radial gradient](https://tailwindcss.com/docs/background-image#adding-a-radial-gradient): `bg-radial-[<position>]`
  - [Adding a conic gradient](https://tailwindcss.com/docs/background-image#adding-a-conic-gradient): `bg-conic-<angle>`
  - [Setting gradient color stops](https://tailwindcss.com/docs/background-image#setting-gradient-color-stops): `from-indigo-500`, `via-purple-500`, `to-pink-500`
  - [Setting gradient stop positions](https://tailwindcss.com/docs/background-image#setting-gradient-stop-positions): `from-10%`, `via-30%`, `to-90%`
  - [Changing interpolation mode](https://tailwindcss.com/docs/background-image#changing-interpolation-mode): `oklab`
  - [Removing background images](https://tailwindcss.com/docs/background-image#removing-background-images): `bg-none`
  - [Using a custom value](https://tailwindcss.com/docs/background-image#using-a-custom-value): Arbitrary values: `bg-linear-[<value>]`, `from-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/background-image#responsive-design): Breakpoint variants, such as `md:`
- [Customizing your theme](https://tailwindcss.com/docs/background-image#customizing-your-theme): Theme variables: `--color-*`
