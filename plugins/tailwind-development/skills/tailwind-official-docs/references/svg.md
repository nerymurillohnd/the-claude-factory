# SVG

## [fill](https://tailwindcss.com/docs/fill)

Utilities for styling the fill of SVG elements.

- [Examples](https://tailwindcss.com/docs/fill#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/fill#basic-example): `fill-indigo-500`, `fill-lime-600`
  - [Using the current color](https://tailwindcss.com/docs/fill#using-the-current-color): `fill-current`
  - [Using a custom value](https://tailwindcss.com/docs/fill#using-a-custom-value): Arbitrary values: `fill-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/fill#responsive-design): Breakpoint variants, such as `md:`
- [Customizing your theme](https://tailwindcss.com/docs/fill#customizing-your-theme): Theme variables: `--color-*`
