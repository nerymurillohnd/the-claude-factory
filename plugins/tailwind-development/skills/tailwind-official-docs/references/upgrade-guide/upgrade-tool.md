# [Run the upgrade tool](https://tailwindcss.com/docs/upgrade-guide#using-the-upgrade-tool)

1. Ask before running it if the working tree has uncommitted changes.
2. Ask before running it if the user only asked a question.
3. Check the tool's Node.js requirement on the page.
4. Create a new branch.
5. Run the command the page shows.
6. Review the whole diff.
7. Check every breaking-change reference: the tool does not catch everything.
8. Test the pages in a browser.
9. Report the tool's output, or why it did not run.
