# Tables

## [border-collapse](https://tailwindcss.com/docs/border-collapse)

Utilities for controlling whether table borders should collapse or be separated.

- [Examples](https://tailwindcss.com/docs/border-collapse#examples): Examples of each utility
  - [Collapsing table borders](https://tailwindcss.com/docs/border-collapse#collapsing-table-borders): `border-collapse`
  - [Separating table borders](https://tailwindcss.com/docs/border-collapse#separating-table-borders): `border-separate`
  - [Responsive design](https://tailwindcss.com/docs/border-collapse#responsive-design): Breakpoint variants, such as `md:`

## [border-spacing](https://tailwindcss.com/docs/border-spacing)

Utilities for controlling the spacing between table borders.

- [Examples](https://tailwindcss.com/docs/border-spacing#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/border-spacing#basic-example): `border-spacing-<number>`
  - [Using a custom value](https://tailwindcss.com/docs/border-spacing#using-a-custom-value): Arbitrary values: `border-spacing-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/border-spacing#responsive-design): Breakpoint variants, such as `md:`
- [Customizing your theme](https://tailwindcss.com/docs/border-spacing#customizing-your-theme): Theme variables: `--spacing`

## [table-layout](https://tailwindcss.com/docs/table-layout)

Utilities for controlling the table layout algorithm.

- [Examples](https://tailwindcss.com/docs/table-layout#examples): Examples of each utility
  - [Sizing columns automatically](https://tailwindcss.com/docs/table-layout#sizing-columns-automatically): `table-auto`
  - [Using fixed column widths](https://tailwindcss.com/docs/table-layout#using-fixed-column-widths): `table-fixed`
  - [Responsive design](https://tailwindcss.com/docs/table-layout#responsive-design): Breakpoint variants, such as `md:`

## [caption-side](https://tailwindcss.com/docs/caption-side)

Utilities for controlling the alignment of a caption element inside of a table.

- [Examples](https://tailwindcss.com/docs/caption-side#examples): Examples of each utility
  - [Placing at top of table](https://tailwindcss.com/docs/caption-side#placing-at-top-of-table): `caption-top`
  - [Placing at bottom of table](https://tailwindcss.com/docs/caption-side#placing-at-bottom-of-table): `caption-bottom`
  - [Responsive design](https://tailwindcss.com/docs/caption-side#responsive-design): Breakpoint variants, such as `md:`
