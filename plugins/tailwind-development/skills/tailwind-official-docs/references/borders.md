# Borders

## [border-radius](https://tailwindcss.com/docs/border-radius)

Utilities for controlling the border radius of an element.

- [Examples](https://tailwindcss.com/docs/border-radius#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/border-radius#basic-example): `rounded-sm`, `rounded-md`
  - [Rounding sides separately](https://tailwindcss.com/docs/border-radius#rounding-sides-separately): `rounded-t-md`, `rounded-r-lg`
  - [Rounding corners separately](https://tailwindcss.com/docs/border-radius#rounding-corners-separately): `rounded-tr-md`, `rounded-tl-lg`
  - [Using logical properties](https://tailwindcss.com/docs/border-radius#using-logical-properties): `rounded-s-md`, `rounded-se-xl`
  - [Creating pill buttons](https://tailwindcss.com/docs/border-radius#creating-pill-buttons): `rounded-full`
  - [Removing the border radius](https://tailwindcss.com/docs/border-radius#removing-the-border-radius): `rounded-none`
  - [Using a custom value](https://tailwindcss.com/docs/border-radius#using-a-custom-value): Arbitrary values: `rounded-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/border-radius#responsive-design): Breakpoint variants, such as `md:`
- [Customizing your theme](https://tailwindcss.com/docs/border-radius#customizing-your-theme): Theme variables: `--radius-*`

## [border-width](https://tailwindcss.com/docs/border-width)

Utilities for controlling the width of an element's borders.

- [Examples](https://tailwindcss.com/docs/border-width#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/border-width#basic-example): `border-<number>`
  - [Individual sides](https://tailwindcss.com/docs/border-width#individual-sides): `border-r`, `border-t-4`
  - [Horizontal and vertical sides](https://tailwindcss.com/docs/border-width#horizontal-and-vertical-sides): `border-x`, `border-y-4`
  - [Using logical properties](https://tailwindcss.com/docs/border-width#using-logical-properties): `border-s`, `border-e-4`, `border-inline-start-width`, `border-inline-end-width`
  - [Between children](https://tailwindcss.com/docs/border-width#between-children): `divide-x`, `divide-y-4`
  - [Using a custom value](https://tailwindcss.com/docs/border-width#using-a-custom-value): Arbitrary values: `border-[<value>]`
