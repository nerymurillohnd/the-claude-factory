# [Colors](https://tailwindcss.com/docs/colors)

Using and customizing the color palette in Tailwind CSS projects.

- [Working with colors](https://tailwindcss.com/docs/colors#working-with-colors): How color utilities apply across properties
  - [Using color utilities](https://tailwindcss.com/docs/colors#using-color-utilities): `bg-*`, `text-*`, `border-*` and every color property
  - [Adjusting opacity](https://tailwindcss.com/docs/colors#adjusting-opacity): Opacity modifiers like `bg-black/75`
  - [Targeting dark mode](https://tailwindcss.com/docs/colors#targeting-dark-mode): `dark:` color variants
  - [Referencing in CSS](https://tailwindcss.com/docs/colors#referencing-in-css): `var(--color-*)` in custom CSS
- [Customizing your colors](https://tailwindcss.com/docs/colors#customizing-your-colors): Add colors under `--color-*` in `@theme`
  - [Overriding default colors](https://tailwindcss.com/docs/colors#overriding-default-colors): Redefine a default `--color-*`
  - [Disabling default colors](https://tailwindcss.com/docs/colors#disabling-default-colors): Remove colors with `--color-<name>-*: initial`
  - [Using a custom palette](https://tailwindcss.com/docs/colors#using-a-custom-palette): Replace every default with `--color-*: initial`
  - [Referencing other variables](https://tailwindcss.com/docs/colors#referencing-other-variables): Semantic colors with `@theme inline`
- [Default color palette reference](https://tailwindcss.com/docs/colors#default-color-palette-reference): Every default color and its OKLCH value
