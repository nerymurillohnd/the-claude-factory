# [Functions and directives](https://tailwindcss.com/docs/functions-and-directives)

A reference for the custom functions and directives Tailwind exposes to your CSS.

- [Directives](https://tailwindcss.com/docs/functions-and-directives#directives): Tailwind at-rules
  - [@import](https://tailwindcss.com/docs/functions-and-directives#import-directive): `@import` for Tailwind and other CSS
  - [@theme](https://tailwindcss.com/docs/functions-and-directives#theme-directive): `@theme` for design tokens
  - [@source](https://tailwindcss.com/docs/functions-and-directives#source-directive): `@source` for extra scan paths
  - [@utility](https://tailwindcss.com/docs/functions-and-directives#utility-directive): `@utility` for custom utilities
  - [@variant](https://tailwindcss.com/docs/functions-and-directives#variant-directive): `@variant` inside custom CSS
  - [@custom-variant](https://tailwindcss.com/docs/functions-and-directives#custom-variant-directive): `@custom-variant` for custom variants
  - [@apply](https://tailwindcss.com/docs/functions-and-directives#apply-directive): `@apply` to inline utilities in CSS
  - [@reference](https://tailwindcss.com/docs/functions-and-directives#reference-directive): `@reference` for `@apply` in modules and `<style>` blocks
  - [Subpath Imports](https://tailwindcss.com/docs/functions-and-directives#subpath-imports): Path aliases in `@import`, `@reference`, `@plugin`, `@config`
- [Functions](https://tailwindcss.com/docs/functions-and-directives#functions): Build-time functions
  - [--alpha()](https://tailwindcss.com/docs/functions-and-directives#alpha-function): `--alpha()` to adjust a color's opacity
  - [--spacing()](https://tailwindcss.com/docs/functions-and-directives#spacing-function): `--spacing()` for theme spacing values
- [Compatibility](https://tailwindcss.com/docs/functions-and-directives#compatibility): Directives kept for v3 compatibility
  - [@config](https://tailwindcss.com/docs/functions-and-directives#config-directive): `@config` to load a JavaScript config
  - [@plugin](https://tailwindcss.com/docs/functions-and-directives#plugin-directive): `@plugin` to load a JavaScript plugin
  - [theme()](https://tailwindcss.com/docs/functions-and-directives#theme-function): Deprecated `theme()`; use CSS variables
