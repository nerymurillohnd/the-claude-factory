# [Dark mode](https://tailwindcss.com/docs/dark-mode)

Using variants to style your site in dark mode.

- [Overview](https://tailwindcss.com/docs/dark-mode#overview): `dark:` variant on `prefers-color-scheme`
- [Toggling dark mode manually](https://tailwindcss.com/docs/dark-mode#toggling-dark-mode-manually): Class-based dark mode with `@custom-variant dark`
  - [Using a data attribute](https://tailwindcss.com/docs/dark-mode#using-a-data-attribute): Dark mode from `data-theme`
  - [With system theme support](https://tailwindcss.com/docs/dark-mode#with-system-theme-support): Light, dark and system toggle with `localStorage`
