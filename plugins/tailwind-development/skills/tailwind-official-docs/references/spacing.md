# Spacing

## [padding](https://tailwindcss.com/docs/padding)

Utilities for controlling an element's padding.

- [Examples](https://tailwindcss.com/docs/padding#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/padding#basic-example): `p-<number>`
  - [Adding padding to one side](https://tailwindcss.com/docs/padding#adding-padding-to-one-side): `pt-<number>`, `pr-<number>`, `pb-<number>`, `pl-<number>`
  - [Adding horizontal padding](https://tailwindcss.com/docs/padding#adding-horizontal-padding): `px-<number>`
  - [Adding vertical padding](https://tailwindcss.com/docs/padding#adding-vertical-padding): `py-<number>`
  - [Using logical properties](https://tailwindcss.com/docs/padding#using-logical-properties): `ps-<number>`, `pe-<number>`
  - [Using a custom value](https://tailwindcss.com/docs/padding#using-a-custom-value): Arbitrary values: `p-[<value>]`, `px-[<value>]`, `pb-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/padding#responsive-design): Breakpoint variants, such as `md:`
- [Customizing your theme](https://tailwindcss.com/docs/padding#customizing-your-theme): Theme variables for these utilities

## [margin](https://tailwindcss.com/docs/margin)

Utilities for controlling an element's margin.

- [Examples](https://tailwindcss.com/docs/margin#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/margin#basic-example): `m-<number>`
  - [Adding margin to a single side](https://tailwindcss.com/docs/margin#adding-margin-to-a-single-side): `mt-<number>`, `mr-<number>`, `mb-<number>`, `ml-<number>`
  - [Adding horizontal margin](https://tailwindcss.com/docs/margin#adding-horizontal-margin): `mx-<number>`
  - [Adding vertical margin](https://tailwindcss.com/docs/margin#adding-vertical-margin): `my-<number>`
  - [Using negative values](https://tailwindcss.com/docs/margin#using-negative-values): Prefix the class with `-` for a negative value
  - [Using logical properties](https://tailwindcss.com/docs/margin#using-logical-properties): `ms-<number>`, `me-<number>`
  - [Adding space between children](https://tailwindcss.com/docs/margin#adding-space-between-children): `space-x-<number>`, `space-y-<number>`
  - [Using a custom value](https://tailwindcss.com/docs/margin#using-a-custom-value): Arbitrary values: `m-[<value>]`, `mx-[<value>]`, `mb-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/margin#responsive-design): Breakpoint variants, such as `md:`
- [Customizing your theme](https://tailwindcss.com/docs/margin#customizing-your-theme): Theme variables for these utilities
