## [width](https://tailwindcss.com/docs/width)

Utilities for setting the width of an element.

- [Examples](https://tailwindcss.com/docs/width#examples): Examples of each utility
  - [Basic example](https://tailwindcss.com/docs/width#basic-example): `w-<number>`
  - [Using a percentage](https://tailwindcss.com/docs/width#using-a-percentage): `w-<fraction>`
  - [Using the container scale](https://tailwindcss.com/docs/width#using-the-container-scale): `w-sm`, `w-xl`
  - [Matching the viewport](https://tailwindcss.com/docs/width#matching-the-viewport): `w-screen`
  - [Resetting the width](https://tailwindcss.com/docs/width#resetting-the-width): `w-auto`
  - [Setting both width and height](https://tailwindcss.com/docs/width#setting-both-width-and-height): `size-px`, `size-4`, `size-full`
  - [Using a custom value](https://tailwindcss.com/docs/width#using-a-custom-value): Arbitrary values: `w-[<value>]`
  - [Responsive design](https://tailwindcss.com/docs/width#responsive-design): Breakpoint variants, such as `md:`
- [Customizing your theme](https://tailwindcss.com/docs/width#customizing-your-theme): Theme variables: `--spacing`
