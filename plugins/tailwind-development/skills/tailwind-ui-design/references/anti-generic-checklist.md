# Anti-generic checklist

Generated interfaces converge on the same defaults, whatever their subject. Each item below is a legitimate tool for some brief; it is a tell when it appears because it is a default, not a decision. When the project or the brief asks for one of them, follow the brief. Otherwise, remove or replace every one you find, and say what you changed.

The first group calibrates aesthetic direction (owned by `frontend-design` when it is installed); the second and third are craft-level tells this skill checks in the markup.

## Direction tells

- [ ] A palette taken from the generic clusters: warm cream with a high-contrast serif and a clay accent; near-black with one acid-bright accent; broadsheet hairlines with zero radius and dense columns.
- [ ] A hero opened with the stock treatment (a big number, a small label, a few stats, a gradient accent) when the subject has something more characteristic to show.
- [ ] One word of a headline accented in another colour or style.
- [ ] Typefaces chosen because they are the usual ones, not for this subject.
- [ ] Copy that sells instead of saying what the thing does; buttons named "Submit"; actions renamed between the button and its confirmation.
- [ ] Entrance animations on every section, hover effects on every card.

## Structure and chrome tells

- [ ] Content chopped into identical cards with the same radius and the same soft grey shadow on each.
- [ ] A tracked-out capitals eyebrow label above every heading; capitals used as the default label style.
- [ ] Numbered markers (01, 02, 03) on content that is not a sequence.
- [ ] Meta strings joined with middle dots everywhere; an arrow appended to every link and button.
- [ ] A monospace face for small data labels as decoration.
- [ ] Everything centred, including long paragraphs, forms and lists.

## Craft tells

- [ ] The same soft shadow under every surface, regardless of elevation.
- [ ] One radius on everything, regardless of element size and role.
- [ ] Coloured accent borders on every card, alert and heading.
- [ ] Grey or `text-white/…` secondary text on coloured surfaces or images.
- [ ] Label-value walls: every field shown as "Label: value" at equal weight.
- [ ] Several solid buttons of equal weight; no visible primary action.
- [ ] Gradient washes, glows and blobs used as filler behind weak hierarchy. Decoration that hides a ranking problem must go, and the ranking must be fixed.
- [ ] Borders around everything, doubled with background changes.
- [ ] Equal spacing everywhere, so nothing groups.
- [ ] Full-width everything because the screen is wide.
- [ ] Placeholder imagery and lorem ipsum left as if final.
- [ ] Only the happy path designed: no empty, error, loading or long-content state.
