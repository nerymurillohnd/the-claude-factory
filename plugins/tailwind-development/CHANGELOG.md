## [0.1.0] - 2026-10-27

### Added

- `tailwind-ui-design` skill: designs, builds, refactors and reviews interfaces in Tailwind CSS v4 with a product designer's craft. It reads your tokens, brand and components first, checks that the type, spacing, colour, elevation and radius systems exist as `@theme` tokens, composes hierarchy before colour, depth and finish, covers every state, verifies the rendered result in each appearance mode and width with measured WCAG 2.2 AA contrast, and critiques it against generic-UI tells. Syntax questions go to `tailwind-official-docs`.
- `tailwind-official-docs` skill: implements, reviews, debugs and refactors Tailwind CSS from the exact official page for each utility family, variant and configuration the task touches, for the Tailwind version your project resolves, and verifies the result with your project's own checks. It carries an index of every page of the Tailwind docs, the 19 framework installation guides included, and the section anchors of the long concept pages, installs Tailwind from zero by following the guide for your framework (or the Vite, PostCSS or CLI path when there is none) and checks that a first class renders, routes editor setup and Prettier class sorting, and checks whether a project can adopt v4, reads Context7 first when you have it, and reports only the documentation a decision depended on.
