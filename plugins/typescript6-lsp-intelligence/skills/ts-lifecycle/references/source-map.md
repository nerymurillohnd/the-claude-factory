# Task-to-source map

Read rows for selected categories; multiple rows normally apply. Entries are research questions, not recommended settings. Start from the official [documentation index](https://www.typescriptlang.org/docs/) if a route changes. The live site generally describes current behavior; establish applicability using the installed compiler and release history. Consult linked subtopics when material.

## Navigation and refresh boundary

This is a bounded ten-category guide, not a site mirror, and embeds no fixed compiler version or compatibility matrix. Tutorials, release notes and current references may describe different contexts: reconcile them rather than silently choosing the newest text. Refresh the pages and histories each task implicates; a page that loaded before establishes neither compatibility nor that it still loads.
