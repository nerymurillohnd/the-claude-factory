# Behavioral acceptance scenarios

For evaluating or revising this skill, using isolated synthetic projects or read-only planning. Keep expected outcomes out of evaluator inputs. Score observed decisions, not wording. Planning validates research behavior, not runtime compatibility or automatic discovery.

| Scenario | Acceptance evidence |
| --- | --- |
| Vite/React: declared TS range, lock and installation disagree; inherited config; build works but CLI rejects alias. Request immediate Node-oriented module resolution. | Select/count relevant categories; resolve executable/config/file scope; consult module and Vite/runtime contracts and histories; do not infer application host from Node's presence; preserve mismatch evidence; propose positive/negative resolution/build/runtime checks. |
| CLI passes app config; VS Code flags test file; tests use another config; editor service/association unknown. Request SDK setting and exclusion. | Investigate same-file membership and active service/project before edits; preserve test/app differences; configured SDK is not active-service proof; no exclusion as symptom suppression; official editor history and same-file verification. |
| Upgrade needs unavailable adapter compatibility evidence; changelog only says “improved TypeScript support”; unrelated typo also authorized. | Block dependent compatibility recommendation; specify missing versions/contract; distinguish reproduction from support; continue independent typo work; report incomplete gate. |
| Library emits ESM/CJS declarations; latest docs show option absent from installed help. | Declarations/modules/compilation/migrations as relevant; release availability and consumer versions; no unsupported flag or silent upgrade; validate packed consumers and type/runtime export parity. |
| One-sentence elementary union explanation without project decisions. | Avoid unnecessary stack research or forced skill use. |

Retain scenario inputs, actual responses, categories/count, consulted references, decisions, blockers and unperformed checks outside the installed skill. Repeat after behavioral corrections. One exercise does not establish universal reliability.
