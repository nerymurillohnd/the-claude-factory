# Maintainer workflow

Operating guide and map of how the maintainer skills work together, for everything outside `plugins/`. Each skill holds only its own step-by-step guide, including what differs between a first time and a later one; this file defines the event and what to load. To manage a plugin, follow `plugin-workflow.md`.

- Load `project-maintainer:write-records` to record an important decision (ADR), to log an idea, task or conflict resolution that cannot be carried out (pending debt), and to close a logged item that is withdrawn, completed or closed (closed debt).
- Load `maintaining-user-docs` to write, update or check the marketplace's own user documentation.
