# Skill routing

Load the skill that governs a task before starting it:

| Task | Skill |
| :-- | :-- |
| Plugin versions and bumps | `plugin-versioning` |
| Releases, tags and GitHub Releases | `plugin-releases` |
| Plugin renames, removals and merges | `plugin-catalog-changes` |
| READMEs, CHANGELOGs, licenses, notices and policy documents | `docs-maintenance` |
| Plugin directory icons | `plugin-icons` |
| ADRs and technical debt | `project-maintainer:write-records` |
| Session handoffs | `project-maintainer:write-handoff` |
| CLAUDE.md and rules | `instruction-engineering:claude-md-and-rules` |
| Hooks | `hook-engineering:hook-development` |
| The plugin CLI and the official plugin docs | `plugin-engineering:cli-commands-guide`, `plugin-engineering:public-marketplace-dev` |
| Pull requests | `github-operations:auto-pr-lifecycle` |
| GitHub Actions workflows | `github-operations:claude-github-actions` |
| Issue forms, templates, labels and Dependabot | `github-operations:github-files-setup` |
