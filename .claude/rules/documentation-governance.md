# Documentation governance

- A governed document, listed under Documentation governance in the project conventions, is written only by the agent that owns it. If you are not that agent, do not write or edit it: a hook denies the write.
- Before any documentation work, and whenever a hook reports a pending documentation chain, load the `documentation-governance` skill and follow it. It says which chain an event sets off and how to run it.
- When the `documentation-governance` skill or the owning agents are not available in the session, as in a cloud thread of a Claude Project, leave governed documents as they are and tell the owner which change is waiting for its documents.
- If you are an owning agent, this rule does not restrict you: write your document as your contract says.
