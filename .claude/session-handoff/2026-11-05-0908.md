- ADR_2026-11-04_pr-agents-deny-tools-in-frontmatter: a limit Claude Code enforces is stronger than an instruction.
- ADR_2026-11-04_pr-agents-read-github-through-mcp-first: one MCP call per fact, with a second path for every read.
- ADR_2026-11-04_init-commands-run-only-when-the-user-types-them: an authorization must come from the user.
