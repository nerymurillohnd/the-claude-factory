## Context for the next session
- Learning: Claude Code 2.1.319 replaces `$` followed by ASCII digits in a skill body when no ASCII letter, digit or `_` follows: `$1`, `x$1`, `$1.00`, `($1)`, `$1é` and `$01` expand, inside backticks too; `$1y`, `$1_` and `${1}` stay.
