# Audit or review

This file is part of the docs-maintenance skill. Follow `../governance.md` for the owner's values, the checks and the conventions, and write each document from its procedure in `../documents/`. Numbered steps run in order.

Someone asks whether the documentation is correct, or drift is suspected.

1. Check each document in scope against its procedure and the files it describes, and write nothing. For a whole plugin, that is its `README.md`, `CHANGELOG.md`, `LICENSE` and `NOTICE.txt` (if it has one); for the whole repository, every document in the skill's table.
2. Show the owner the findings, grouped by file.
3. Fix only what the owner approves.
