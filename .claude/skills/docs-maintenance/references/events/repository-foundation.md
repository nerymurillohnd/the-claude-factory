# Repository foundation

This file is part of the docs-maintenance skill. Follow `../governance.md` for the owner's values, the checks and the conventions, and write each document from its procedure in `../documents/`. Numbered steps run in order.

The repository's own documents are created or rebuilt, for example when the marketplace is set up or restructured. Gather every owner value first: the copyright line, the reporting channels, the security policy, the privacy policy's effective date and the marketplace display name.

1. Root `LICENSE`, `CODE_OF_CONDUCT.md`, `SECURITY.md` and `PRIVACY.md`.
2. `CONTRIBUTING.md` and `SUPPORT.md`, which link to the code of conduct and the security policy.
3. Root `README.md`, which links to every policy and lists the catalog.
4. Root `CHANGELOG.md`, which takes the marketplace display name from the root README's title.
