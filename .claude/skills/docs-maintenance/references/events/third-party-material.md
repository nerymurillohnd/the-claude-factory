# Third-party material changes

This file is part of the docs-maintenance skill. Follow `../governance.md` for the owner's values, the checks and the conventions, and write each document from its procedure in `../documents/`. Numbered steps run in order.

Material from another author is added to a plugin, updated to another version or removed.

1. The plugin's `NOTICE.txt`: the source, its exact version and its license for each work. A source with no license can't be redistributed: tell the owner before anything is written.
2. The credits and license notes in the plugin's `README.md`.
