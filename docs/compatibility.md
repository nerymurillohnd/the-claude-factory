# 🧭 Compatibility

> Which parts of a plugin load in **Claude Code** and in **Claude**, so you know what you'll get before you install.

You can install the same plugin in Claude Code and in Claude, but each one loads a different subset of what the plugin contains. A surface silently skips components it doesn't support, so a plugin can feel complete in one place and partial in another. **Every plugin README has a Compatibility table** that applies these rules to that plugin.

---

## 🧩 Components by surface

- **Claude Code**: the terminal, the IDE extensions (VS Code and JetBrains), the **Code** tab of the Claude desktop app, and cloud sessions on the web.
- **Claude**: claude.ai on the web, the Claude desktop app and the mobile apps.

> [!NOTE]
> A hook that runs a program, such as a formatter, a linter or a compiler, works only where that program is installed. In Claude Code it runs on your computer, so it uses the copy you installed. Claude's docs don't say where a hook runs in Claude, so such a hook may find nothing to run there. Each plugin's README names the programs its hooks need.

## 💬 Conversations in Claude

Claude runs a conversation with the full set of plugin components above when it can run tasks there, and with skills, commands and remote connectors otherwise, for example on a device that can't run tasks or on a plan that doesn't have the unified Claude experience yet. Anything on your computer, such as a local MCP server, needs Claude Desktop open. Claude's plugin docs don't list monitors or workflows, so treat them as Claude Code only.

## 🗺️ Where you add plugins

|                         | Claude                                                       | Claude Code                                        |
| :---------------------- | :----------------------------------------------------------- | :------------------------------------------------- |
| **Where**               | **Customize** → **Plugins**                                  | `/plugin` in a session, or `claude plugin install` |
| **Install attaches to** | Your claude.ai account                                       | The machine (user, project or local scope)         |
| **Sync**                | Installs also appear in Claude Code as `<plugin>@synced`     | Shell installs stay on that machine                |
| **Limits**              | Up to 25 added marketplaces; 5,000 files / 200 MB per plugin | None per account                                   |

## 💡 What this means for you

- 🧑‍💻 **Using Claude Code?** Everything in a plugin works.
- 🖥️ **Using Claude?** Skills, commands and remote MCP servers work in every conversation. Agents, hooks and local MCP servers work where Claude can run tasks. LSP servers, output styles, themes, default settings, monitors and workflows are skipped. Plugins with a `bin/` folder can't be installed: their README says so up front.
