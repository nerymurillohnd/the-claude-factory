# 🤝 Contributing

Thank you for wanting to make **The Claude Factory** better! 💛

## How contributions work here

This marketplace is built and maintained by its owners, who review, develop, test and release every change. To keep every plugin consistent, secure and supported, **pull requests are not accepted** — but your input drives what we build next.

| You can | How |
| :-- | :-- |
| 🐞 Report bugs | [Bug report](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=bug_report.yml) — with versions and steps to reproduce |
| ✨ Shape existing plugins | [Feature request](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=feature_request.yml) |
| 💡 Inspire new plugins | [Plugin idea](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=plugin_idea.yml) — describe the workflow, we design the plugin |
| 📝 Improve the docs | [Documentation issue](https://github.com/nerymurillohnd/the-claude-factory/issues/new?template=docs_issue.yml) — point to the page and the fix |
| 👍 Signal priority | React with 👍 on issues you care about — we use reactions to prioritize |
| 🔐 Keep users safe | Report vulnerabilities privately per the [Security policy](./SECURITY.md) |

## What happens after you open an issue

1. **Triage** — we label it and may ask for more details (`status: needs-info`).
2. **Decision** — confirmed issues are scheduled; others get a clear explanation.
3. **Release** — fixes ship as a new plugin version with a changelog entry, and we link the release in your issue.

## Code of conduct

Be kind and constructive. See our [Code of Conduct](./CODE_OF_CONDUCT.md).
